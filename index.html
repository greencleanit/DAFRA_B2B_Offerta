Intestazione Società, Logo & Database Cloud Google Drive

Configura i dati aziendali e collega il tuo Google Apps Script per condividere listini e storico offerte tra tutti gli agenti su Netlify.

Procedura rapida su Google Drive:

  1. Crea un nuovo Foglio Google sul tuo Drive e rinomina il primo foglio in DB.
  2. Dal menu in alto vai su Estensioni > Apps Script, incolla lo script qui sotto e salva.
  3. Clicca su Esegui deployment > Nuovo deployment > App web, imposta Chi può accedere: Chiunque e copia l'URL /exec qui sopra.
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('DB');
  var val = ss.getRange('A1').getValue() || '{}';
  return ContentService.createTextOutput(val).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('DB');
  ss.getRange('A1').setValue(e.postData.contents);
  return ContentService.createTextOutput('{"status":"ok"}').setMimeType(ContentService.MimeType.JSON);
}
